# Nuru App
Nuru - is an app that can play multiple chosen ambient audio (whatever user wants) with custom ambience included.

### Features:
| Feature | Description | Implementation |
| Main Interface | Basic app design | None |
| Audio seamless looping | Proper seamless loop of an audio | None |
| Nook Mode | Opens in a fullscreen, dynamic cozy nook room design that changes based on sounds enabled | None |
| Presets | Save/load presets of your settings and audio toggles | None |
| Settings | Self-explanatory | None |
| Volume | Audio volume for all of audio and individually | None |
| Image support | Thumbnails for each audio slot | None |
| Proper perfomance | Optimization so it doesnt eat up ram | None |
| Play/pause | pause and play audio | None |
| Audio database | Download custom user-made audios right from the app | None |
| Timer | Timer to pause all audio after | None |
